# BibCiTeX 0.8.1

## 公式兼容性

- 正确识别文献导出内容中简单数学表达式的双反斜杠命令，例如 `\\alpha`、`\\ell`。
- 保留换行和矩阵等多行 TeX 结构的原有语义，导出时仍保留原始 BibTeX 内容。
- 修正公式命令规范化后的高级搜索匹配位置，保持与显示文本一致。

## macOS

- 修复 `\ell` 等窄公式字符在 SVG 渲染时消失的问题，保留公式尺寸与对齐。
- 公式图像渲染失败时显示原始公式文本。
- 主工作台、托盘窗口以及侧栏和详情弹出面板始终隐藏滚动条，滚动或悬停时也不显示，仍可正常滚动。
