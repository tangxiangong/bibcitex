# BibCiTeX 0.7.1

本次更新完善原生桌面体验，修复快捷引用的跨应用粘贴，并改进更新下载与 Windows 安装流程。

## 新增与改进

- macOS 和 Windows 新增原生设置窗口，集中管理界面语言、外观、更新通道和自动更新；macOS 支持使用 `⌘,` 打开设置。
- 托盘浏览窗口新增浮动文献详情，默认收起以保留列表空间；点击引用键即可复制，按 `Esc` 关闭详情。
- 优化主窗口分栏、列表选中效果和滚动条显示，改善快捷引用窗口的行对齐与选中标记。
- macOS 优先采用系统图标，更新托盘图标；Windows 改善标题栏、深浅色主题、设置布局与图标显示。
- 改善公式显示：修复 macOS 公式在首次显示与缓存加载时尺寸不一致的问题，优化 Windows 行内公式的尺寸、间距和基线对齐。
- 两个平台的“关于”窗口新增许可证信息。

## 问题修复

- 修复 macOS 快捷引用跨应用粘贴时可能触发的崩溃，改善粘贴前的焦点切换；打开快捷引用窗口时保持主窗口隐藏。
- 两个平台在跨应用粘贴失败时自动将引用内容复制到剪贴板，便于手动粘贴。
- 修复 macOS 不同复制按钮之间的反馈相互干扰，以及连续复制时旧提示覆盖新提示的问题。

## 更新与安装

- 应用内更新优先使用腾讯云 COS，在更新信息请求或安装包下载失败时回退至 GitHub，保留下载完整性校验。
- Windows 按需安装缺失的 .NET、Visual C++ 和 Windows App Runtime 运行库，复用已安装的兼容版本；安装或首次启动时如缺少依赖，需要联网下载。
- 最低系统要求调整为 macOS 13 Ventura 和 Windows 10 1809（内部版本 17763）；继续支持 Apple Silicon、Intel Mac，以及 Windows x64 和 ARM64。

macOS 跨应用粘贴需要在系统设置中授予 BibCiTeX 辅助功能权限。
